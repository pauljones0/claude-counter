Claude Counter shows approximate conversation tokens, an estimated cache timer, and session/weekly usage on claude.ai.

Usage bars sit below the composer, with responsive wrapping and light/dark themes. Model-specific weekly caps appear when Claude reports them. Reset countdowns and exact local reset times help you understand each window; a keyboard-accessible refresh button updates the figures on demand.

Usage loads on new-chat pages and refreshes about once a minute while the tab is visible. Failed requests show an unavailable or stale notice. Switching organizations clears previous account values.

Token counts use a local generic tokenizer and exclude system prompts, project knowledge, images/PDFs and hidden reasoning. Counts can become inaccurate after compaction. The mini bar is a 200k reference scale, not a model-specific limit. Cache timing is an estimate, not a billing or discount guarantee.

Privacy: no analytics, developer servers, stored conversation history or API keys. The extension reads Claude's own responses and makes authenticated, read-only requests only to claude.ai. No additional storage, notification or background permissions.
